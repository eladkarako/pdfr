26.11.11
+ replaced **Linearize** and **Compact** with **Normalize**: a qpdf-driven dialog with individually selectable stream compression, decode-all/recompress-Flate, compression level 9, image optimisation with a 0-100 JPEG quality, newline-before-endstream, unreferenced-resource removal, inline-image externalisation, linearization and best-effort PDF/A-2b.
+ Normalize runs the selected transformations in a single qpdf pass, so decoding, image optimisation, compression and linearization feed each other without intermediate PDFs.
+ PDF/A-2b adds the XMP identification, an sRGB output intent with an embedded ICC profile, PDF 1.7 and an unencrypted output; fonts and content are left untouched, so it is labelled best effort.
+ the metadata editor now also edits the file created and modified timestamps, with a separator before the document properties.
+ images show an ordered EXIF/XMP set (camera, lens, exposure, GPS, caption, keywords, creator, rights, rating and ICC profile) followed by every other EXIF, IPTC, PNG and XMP entry the file already contains.
+ JPEG, PNG and WebP metadata is written in place through ExifInterface and the PNG chunk helpers; HEIC, IPTC and ICC edits are read-only and are kept in the metadata sidecar, with a message explaining the partial write.
* some project structure for APK size reduction, but still keeping being reverse-engineer friendly result, for now only English result since the app ships with only English language anyway, moving const and values from around the code to allow easier modification and future translations, for the C++ code - using .h file. 

26.11.10
+ added **Fix PDF** to the overflow menu: qpdf's fix-qdf repair cycle now runs entirely through the bundled native library (write QDF, repair stream lengths and the cross-reference table, rewrite as a normal PDF). The repaired `... (fixed).pdf` replaces the current document.
+ **Fix PDF** appears only when the open document is a PDF, or when nothing is open. With no document it opens the picker first and repairs the chosen PDF as soon as it loads; non-PDF documents are reported instead.
+ the overflow menu is now enabled on the empty screen and offers **Fix PDF** there; reader checks cover the empty, plain-text and PDF menus.
+ added **Exit** as the last overflow entry, above a divider and available in every state: it removes the task from recents and ends the process, stopping the reader and qpdf threads instead of leaving the app cached in the background.

26.11.9
* to work around the lazy text container, that only selects all viewport lines, I'll just skip having select all since it is just a midway to copy the selection, instead I'll have a direct copy all that ignores the selection, side by side with manual selection and copy. entry is in touch menu as well as in the menu (tests and generator added).

26.11.7
+ treats source and configuration files as plain text: JSON, YAML, TOML, CSV/TSV, C/C++, Java, JS/TS, shell, XML and similar suffixes are opened through a temporary `.txt` copy; an unknown suffix is detected from its bytes when MuPDF cannot open it.
+ long-press now opens a page menu instead of selecting a word: choose **Select all** to highlight every text block on the page, then **Copy**; tapping elsewhere dismisses it. The old drag handles and range adjustment were removed.
+ the temporary copy is byte-for-byte identical: PDFr never adds a byte-order mark. MuPDF's own content detector still treats a file whose first line starts with `# ` as Markdown, so such a comment may render as a heading without the marker.
+ advertises `text/*` plus the common application text MIME types, so those files work in other apps' "Open with" and share menus without a separate PDFr entry per extension.
+ opens the remaining formats MuPDF 1.28.5 supports: Markdown, MOBI/PRC/PDB, CBT, HTML/XHTML, SVG, common images and PNM/PAM.
+ PDFr now advertises those types as an "Open with" and share target. Office documents (DOCX/XLSX/PPTX/HWPX) are not supported.
+ plain-text aliases now cover .log, .nfo and the longer Markdown suffixes through a temporary canonical-suffix copy.
+ added a middle Save button next to Open that copies the current document in its existing format, keeping the original filename, extension and, where the provider supports it, the original modification time.
+ toolbar order is now share, info, open, save, menu; "Open another" was removed from the overflow menu because Open has its own button.
+ test fixtures now include guide.md, image.png and image.ppm, with unit tests for the new format mappings and aliases.
+ pinch zoom now anchors on the midpoint between the fingers instead of the first finger, pans immediately during the gesture, and re-applies its anchor once the delayed layout/reflow catches up, so a pinch no longer drifts towards the starter finger.
+ the page indicator is slightly larger, starts dimmer and fades to almost invisible over five seconds; scrolling, panning, zooming or changing pages wakes it.
+ the overflow menu and the document-info dialog are capped at three quarters of the screen height and scroll their contents.
+ added `ZoomMathTest` plus fixed-layout/reflow zoom instrumented tests, `tools\zoom-probe.ps1`, which records before/down/mid/late/settled screenshots and reports whether a pinch settles without a jump, and `tools\reader-actions.ps1` for reproducible long-press, tap, menu and info checks.
+ plain text now uses a dedicated Compose reader: one continuous page (default), optional vertical paging, line wrap with horizontal panning when wrap is off, right-to-left direction/alignment, line numbers on the left (right in RTL), monospace and a 5-40 pt text size (12 pt default). Pinch and double-tap are disabled for plain text.
+ reflowable EPUB/Markdown/HTML use the text-size setting instead of pinch zoom; fixed-layout PDFs and images keep pinch/double-tap zoom.
+ plain text selection uses a single `SelectionContainer` around the `LazyColumn`, so the system toolbar can select across paragraphs and copy them; line numbers are excluded.
+ the toolbar is always visible; with no document open, share, info and save look disabled, and the overflow menu is disabled too.
+ document info is now an editor: Apply/Cancel at the top, editable filename and extension, existing metadata only, ISO `yyyy-MM-ddThh:mm:ss` dates with pickers, and clearing a value removes it. Edits stay in a draft until Apply, which rewrites a PDF's Info dictionary or a sidecar for other formats and reloads the document. Encryption/secured rows were removed.
+ Save as and Share use the edited display name/timestamp; PDF metadata edits are part of the shared/saved bytes.
+ added date, plain-text, metadata-draft and sidecar unit tests, a PDF metadata rewrite instrumented test, and new `reader-actions.ps1` actions for metadata, text size and plain-text toggles.
