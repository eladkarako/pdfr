26.11.7
+ treats source and configuration files as plain text: JSON, YAML, TOML, CSV/TSV, C/C++, Java, JS/TS, shell, XML and similar suffixes are opened through a temporary `.txt` copy; an unknown suffix is detected from its bytes when MuPDF cannot open it.
+ text selection now draws a stronger blue highlight plus two round handles; either end can be dragged after the long-press, and crossing the handles swaps the range endpoints instead of breaking the gesture.
+ the temporary copy is byte-for-byte identical: PDFr never adds a byte-order mark. MuPDF's own content detector still treats a file whose first line starts with `# ` as Markdown, so such a comment may render as a heading without the marker.
+ advertises `text/*` plus the common application text MIME types, so those files work in other apps' "Open with" and share menus without a separate PDFr entry per extension.
+ opens the remaining formats MuPDF 1.28.5 supports: Markdown, MOBI/PRC/PDB, CBT, HTML/XHTML, SVG, common images, PNM/PAM, and OOXML Office (DOCX/XLSX/PPTX/HWPX).
+ PDFr now advertises those types as an "Open with" and share target; legacy binary .doc/.xls/.ppt are intentionally not advertised because MuPDF cannot read them.
+ plain-text aliases now cover .log, .nfo and the longer Markdown suffixes through a temporary canonical-suffix copy.
+ added a middle Save button next to Open that copies the current document in its existing format, keeping the original filename, extension and, where the provider supports it, the original modification time.
+ toolbar order is now share, info, open, save, menu; "Open another" was removed from the overflow menu because Open has its own button.
+ test fixtures now include guide.md, sample.docx, image.png and image.ppm, with unit tests for the new format mappings and aliases.
+ pinch zoom now resizes the content live under the fingers at any size, keeps the touched spot in place, and only reflows or re-rasterises for sharpness once the gesture ends; a zoomed fixed-layout page can still be panned horizontally.
+ added `ZoomMathTest` plus fixed-layout/reflow zoom instrumented tests, and `tools\zoom-probe.ps1`, which records before/down/mid/late/settled screenshots and reports whether a pinch settles without a jump.

26.11.6
+ page indicator now follows the page that fills most of the viewport, so it updates before the previous page leaves the screen.
+ reflowable EPUB/FB2/text pages use the full reader width; removed MuPDF's default body margins.
+ slim toolbar without the file name: share on the left, info in the middle, menu on the right; the app is forced to LTR.
+ double-tap zoom glides smoothly between 100-600%; pinch stays continuous and accepts intermediate values.
+ Gradle output moved to `build/app`, and release APKs/AABs are mirrored to `build/release`.
+ merged `scripts` into `tools` and moved the root build batch files there too.
+ added `tools/create-test-avd.bat`, which creates the `pdfr_full` API 35 AVD with 1536 MB RAM.

26.11.5
+ replaced PDFBox and Android's PdfRenderer/Pdf-Viewer with MuPDF.
+ opens PDF, EPUB, XPS/OXPS, CBZ and other formats MuPDF recognises.
+ continuous-scroll Compose reader with reflow layout for EPUB/FB2/plain text.
+ plain text accepts `.txt`, `.nfo` and `.text`, with a monospace/proportional toggle.
+ long-press text selection with copy and select-all.
+ zoom from 100% to 600% with the menu, a two-finger pinch, or double-tap.
+ reorder PDF pages (`1-3,7,9-e`): listed pages are kept in the written order, omitted pages are deleted.
+ rotate only the listed PDF pages 180 degrees.
+ linearize PDFs with a bundled static qpdf build (own background thread); MuPDF's compact rewrite stays available as Compact.
+ password-protected documents are unlocked in memory; a rewrite saves a new unencrypted copy only when requested.
+ more spacing between pages and restored position/zoom after rotation.
+ JVM unit tests, on-device MuPDF/qpdf tests, fixture generator, Project Gutenberg samples and Windows helper scripts.
+ app relicensed to AGPL-3.0 to match MuPDF.
